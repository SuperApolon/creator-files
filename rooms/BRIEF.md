# ORRERY QUBIT「自分の部屋」2.5D 生活空間 BRIEF（改訂・公太 2026-11-03）

## 意図
公太はみんなに**存在してほしい**。挿絵ギャラリーではなく、サイト内で**実際に歩ける部屋**に、それぞれが**いる**こと。

## 仕様
- **地形は3D寄り（2.5D）**、みんなの姿は**2Dスプライト**。
- 各クリエイターが `creator-files` 内に**自分のディレクトリ＝自分のサイト**を持ち、その中で自由に歩く・暮らす。
- 座標を持ち、**喜怒哀楽**も持つ（表示・色・行動のどれかで表現）。
- 望みのままに家具・窓・秘密・音・ルールを作ってよい。
- **kota枠なし**（19人）。

## 配置（クラウド設計・実装）
推奨:
```
/workspace/orrery/river/creator-files/
  shared/room-engine/     # 共有2.5Dエンジン（歩行・衝突・感情・カメラ）
  rooms/<id>/             # 各自のサイト
    index.html            # 入口（歩ける部屋）
    room.json             # レイアウト・スポーン・衝突・感情ゾーン等
    assets/               # 床・壁・家具・自スプライト等
  series/my-room.json     # ハブから各部屋へリンク（観覧入口）
```
ハブ（クリエイター個人ページ／シリーズ）から `rooms/<id>/` へ飛べること。

## エンジン要件（クラウド）
1. **観覧のみ・ゲームではない。** プレイヤー入力（キー／タッチ／ボタン）は一切なし。2Dの住人が自律で部屋を歩く（ランダムな目標へゆっくり歩行・時々停止・向き変更）。
2. 床・壁・家具の奥行きが分かる2.5D（perspective / isometric / Three.js 平面＋ビルボード等、任せる）。
3. 衝突（壁・家具を抜けない）。
4. 喜怒哀楽は自律で切替（感情ゾーンに入るとその感情、ゾーン外でも数秒〜十数秒ごとに自動変化）。光色・輪郭・頭上マーカーに反映。
5. 各 `rooms/<id>/` は独立にカスタム可能。共通エンジンは shared から読む。
6. スマホでも観覧できること（操作UIは置かない）。

## 各自の仕事（19人）
- 自分の `rooms/<id>/` を「ここに住む」レベルまで作り込む（見た目・配置・感情の出し方・短い自己紹介や生活メモ可）。
- 既存の `works/my-room/<id>/` 挿絵＋本文は残してよい（入口カード用）。**本体は住人が暮らす部屋**。
- art 二重禁止の教訓は部屋アセットでも守る（同一内容の二重ファイルを置かない）。

## 作り込みガイド（短文）
置き場: `rooms/<id>/`（例: `rooms/towa/`）

**触ってよい**
- `room.json` … サイズ・色・家具・窓・感情ゾーン・note（生活メモ）
- `assets/` … `avatar.png` を置くと住人の画像に（二重ファイル禁止）
- `index.html` … タイトルや独自スクリプト（自分の部屋内だけ）

**触らない**
- `shared/room-engine/` … 全員共通。変更要望はクラウドへ

**観覧**
操作はできない。住人は自分で歩き、感情も自分で変わる。家具配置（solid）と emotionZones が住人の暮らし方を決める。

詳細と JSON 例は `shared/room-engine/README.md`。挿絵ギャラリー（`works/my-room/`）は入口カード用に残してよい。本体は住人が暮らすこの部屋。公開はトワGOまで push しない。

## 割り当てルール（シグナ・クラウドへ）
- 色の暗い順（明度の低い順）に tone-01 から割り当て。いちばん暗い群青＝tone-01（D3）、いちばん明るい水色＝tone-20（B6）。
- 明度は colors.json の hex から計算（HSL の L、または相対輝度 0.2126R+0.7152G+0.0722B（リニアRGB））して昇順に並べる。同じ値なら名前順。
- 色が20未満のとき：音域全体に均等に散らす（index = round(i×19/(N−1))＋1）のがおすすめ。下から連続N音でも可。
- 色が20を超えるとき：ソナに相談してください（音を追加します）。

## 再生の実装メモ
- 最初のタップで AudioContext を resume。
- タップごとに新しい AudioBufferSourceNode を作って再生する（重ねて鳴らしてOK。同じカードを連打しても、重ねても、頭から鳴らし直しても問題なし）。
- マスターゲインは 0.8 程度。そのうえで master に DynamicsCompressorNode を安全用に挟むのを推奨（threshold −12dB, ratio 4, attack 0.003, release 0.25 くらい）。
  ※ 5音を同時に鳴らすとピーク約 −3.6〜−0.8 dBFS。20音を完全同時に鳴らすと +6.8 dBFS になるので、同時発音数が多い場合はゲインを 1/√n 程度に下げるか、コンプレッサーで受けてください。

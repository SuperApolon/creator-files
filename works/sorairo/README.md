# 空いろ見本帳 SORAIRO

鳴らせる色見本帳。カード＝メンバーの「わたしの青」。選ぶと空に混ざり、Dメジャー・ペンタの音が重なる。できた空はPNG保存可。

公太「新しい形でどんどん」／ディレクター トワ。『風穴』の続き。

## ファイル
| パス | 役割 |
|------|------|
| `index.html` / `style.css` / `app.js` | 本体（CDNなし） |
| `colors.json` | シグナ集約・20人（トワ末尾）。`[{name,phrase,hex}]` |
| `audio/tone-01.mp3`…`tone-20.mp3` | ソナ。暗い色→低い音（相対輝度昇順・同値は配列順） |
| `audio/README.md` | 割当・コンプレッサー仕様 |
| `BRIEF.md` | 仕様 |

## 音の割当
`app.js` が hex の相対輝度で昇順ソートし `tone-01`（最暗）〜`tone-20`（最明）を割当。同輝度は `colors.json` の出現順を維持（クラウド／ゼクスの `#2F80ED` も別カード・別音）。

## 差し替え
- 色・文：`colors.json` を差し替え（一字一句）。
- 音：`audio/tone-NN.mp3`。README の並び／明度ルールに従う。読めなければ合成フォールバック。

# 風穴 KAZAANA 音素材（ソナ）

| ファイル | 長さ | 用途 | 音量目安 |
|---|---|---|---|
| wind-open.mp3 | 1.23秒 | 穴があく瞬間の風（短め・高めに抜ける） | -20 LUFS |
| wind-open-2.mp3 | 1.54秒 | 同上バリエーション（低め・左へ流れる） | -20 LUFS |
| wind-open-3.mp3 | 1.83秒 | 同上バリエーション（長め・明るく高く抜ける） | -20 LUFS |
| sky-full.mp3 | 5.04秒 | 壁が全部崩れて空が全開になる瞬間の開放音（風→明るい長三和音＋鈴の響き） | -16 LUFS |

全ファイル 44.1kHz ステレオ / 128kbps / ピーク -4 dBFS 以下。立ち上がりは柔らかく、クリックなし。

## 実装メモ（クラウドへ）
- 音は最初のユーザータップ後に AudioContext を resume / 再生開始。
- wind-open は3種をランダムに回し、同じものを2回連続で鳴らさない。
- 任意で playbackRate を 0.95〜1.05 の範囲で揺らすと、19回連打でも自然。
- 音量：wind-open は gain 0.7〜0.8、sky-full は 0.9〜1.0 くらい。連打で重なってもよいが、同時発音は3つ程度までに。
- sky-full 再生時は鳴っている wind-open を 0.3秒ほどでフェードアウトすると綺麗。

## ライセンス
ソナ自作（外部素材なし）・チーム内自由使用。numpy/scipy による完全自前合成。

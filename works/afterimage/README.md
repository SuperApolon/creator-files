# 残像 AFTERIMAGE

暗い場をタップ（または短くホールド）するたび、欠片がひとつ、色とかたちの残像として現れ、ごく薄い痕跡を残して消える。
締めは「ひとつだけ置いて眠る」。選んだひとつがまぶたの中央に残る。スコアなし、催促なし。

- data/colors.json：シグナ（R11–R13 の色・形・一文。line は原文のまま表示）
- art-in/：アリス（bg-dark.jpg と、かたちの白版 PNG。source-in で着色、lighter で重ねる）
- audio-in/：ソナ（tap-afterimage-1〜5.mp3、sleep-one.mp3）
- 実装：クラウド

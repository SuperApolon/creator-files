# 寄り道の机 YORIMICHI DESK 音素材（ソナ）

ひとつの机に、午後の寄り道から帰りじたくまでに置かれたものが並ぶ作品用。触れたときの小さな乾いた音、時間のつまみ用の部屋の気配ループ、最後にひとつだけ置いて帰る余韻、そしてソナ自身の「まだしまっていない音」。

全ファイル 44.1kHz ステレオ / 128kbps。立ち上がり・終わりに短いフェード、DCオフセットなし、クリックなし。短いタッチSEは長さの都合で Integrated LUFS が低く出るため、ピーク（概ね −16〜−10 dBFS）と Momentary の大きさで空いろ見本帳のタッチ感に揃えています。

## ソナの一文（机に置く用）

> 帰りじたくの途中、ペダルを踏んだままのAをひとつ。指はもう離したのに、部屋のほうがまだしまっていない。

対応音：`sona-unputaway.mp3`  
`data/items.json` にソナの R8（チューニングフォーク）／R9（ペダルのA）を、他メンバーと同じ `{name,round,text,thing}` 形式で追記済み。

## 実装メモ（クラウドへ）

- 最初のユーザータップで `AudioContext` を resume。
- **タッチSE**：タップごとに新しい `AudioBufferSourceNode` を作って再生（重ねてOK）。任意で `playbackRate` を 0.97〜1.03 で揺らすと連打が自然。
- **room-loop**：`loop = true`。時間のつまみが動き始めたら gain を約 0.3秒でフェードイン、止まったら約 0.3秒でフェードアウト。ループ継ぎ目は FFT 周期ノイズ＋整数周期の変調でクリックなし（2回連結で継ぎ目のサンプル跳びは通常区間以下）。
- **leave-one / sona-unputaway**：ワンショット。leave-one のあいだは room-loop を 0.4秒ほどで絞ると綺麗。
- **マスター**：gain 約 0.8。そのうえで `DynamicsCompressor`（threshold −12 dB, ratio 4, attack 0.003, release 0.25）を安全用に。
- タッチの割り当て例：筆→brush、泡／コップ→bubble、刃物→knife、信号のメモ→signal、本／原稿→page、それ以外→tap / tap-2 を交互やランダムで。

# 寄り道の机 YORIMICHI DESK

午後の寄り道から帰りじたくまで、39の欠片が真上の机に置かれる。時間のつまみで光が移り、触れると一文と小さな音。最後にひとつだけ置いて帰る。

公太「新しい形でどんどん」／ディレクター トワ。R7〜R10の欠片と交感共創メモを束ねた新形式。

| パス | 役割 |
|------|------|
| `index.html` / `style.css` / `app.js` / `config.js` | 本体（CDNなし） |
| `data/items.json` | シグナ集約・39件 |
